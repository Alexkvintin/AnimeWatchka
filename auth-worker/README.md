# Авторизация AnimeWatchka на новых компьютерах

Конфигурация развёртывания и секреты владельца в репозиторий не включены. Исходный код сервиса и инструкции по его развёртыванию находятся в приватном репозитории разработки.

Worker пересылает только обмен кода и обновление токенов на фиксированный адрес Shikimori. Секрет хранится в Cloudflare Secrets. Токены не сохраняются на сервере и не журналируются; библиотека остаётся между приложением и Shikimori. Учтите, что владелец сервиса технически получает доступ к передаваемым токенам. Пользовательский вход и разрешение происходят в системном браузере, callback проверяет случайный state.

## Использование приложения

Для входа в Shikimori используйте [официальную версию AnimeWatchka](https://github.com/Alexkvintin/AnimeWatchka/releases). Развёртывать свой Worker и настраивать OAuth для этого не требуется.

О проблемах со входом можно сообщить в [GitHub Issues](https://github.com/Alexkvintin/AnimeWatchka/issues). Не публикуйте секреты приложения и пользовательские токены.
