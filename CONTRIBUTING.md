# Работа с проектом

Основная ветка — `main`. Для изменений создавайте отдельную ветку (`codex/<описание>` или свою), запускайте тесты и оформляйте pull request.

- `AnimeApp/` — Avalonia UI, модели, провайдеры, синхронизация и воспроизведение.
- `AnimeApp.Tests/` — тесты и фиксированные входные данные.
- `auth-worker/` — сервис обмена OAuth-кода, без секретов.
- `installer/` — сценарии Inno Setup и сборка.
- `tools/` — подготовка нативного движка и диагностические инструменты разработчика.

Перед отправкой: `git status`, `git diff --cached`, сборка и обычные тесты из README. Проверки реального аккаунта не включать автоматически: они требуют отдельного разрешения и тестового окружения. Не загружать логи, токены, локальные БД, личные настройки, снимки профиля, `bin/obj`, `.local`, `.dotnet`, `artifacts` или содержимое `%LOCALAPPDATA%/AnimeApp`.

Для выпуска синхронизировать версию в проекте и Inno Setup, обновить `ReleaseNotes` и `CHANGELOG.md`, проверить обновление поверх предыдущей версии. Секреты Worker вводятся только через `wrangler secret put`. Перед публичным распространением отдельно проверить комплект лицензий и исходников сторонних бинарных компонентов.
